# Chronos

Interactive horizontal-scrolling Bible timeline — Adam through the resurrection of Jesus (~AD 33).

Built with vanilla TypeScript and Vite. Chronology follows Ussher (pre-monarchy) and Thiele (divided kingdom).

## Scripts

```bash
npm install       # install dependencies
npm run dev       # start dev server
npm run build     # type-check and build for production
npm run preview   # preview production build locally
```
